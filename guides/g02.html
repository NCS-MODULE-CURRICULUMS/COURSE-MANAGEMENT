NCS 기반 훈련과정 편성

직무 선정에서 편성표 제출까지 · NCS 29차 · 대분류 20.정보통신

도구 — 이 문서의 3 ~ 8단계는 훈련과정 편성표 생성기 로 바로 실행할 수 있습니다. 세분류를 고르면 능력단위 1,254건에서 해당 직무의 목록이 나오고, 시간과 적용비율이 자동 계산됩니다.

NCS는 대분류 → 중분류 → 소분류 → 세분류 4계층이고, 세분류가 하나의 직무입니다. 훈련과정은 세분류 단위로 붙입니다. 세분류 아래에 능력단위가 있고, 능력단위 아래에 능력단위요소가 있습니다.

앞 8자리 20010707 = 세분류코드 (생성형AI엔지니어링)
뒤 2자리 05       = 능력단위 번호 (프롬프트 구현)

버전 표기가 중요한 이유

_YYvN 은 그 능력단위가 언제 개발 · 개선되었는지를 나타냅니다. 19v4 는 2019년 4차, 25v1 은 2025년 1차입니다. 번호가 낮으면 오래된 직무이고, 학습모듈도 그만큼 오래된 내용일 수 있습니다.

흔한 실수 — 개정으로 폐지된 능력단위를 편성표에 쓰는 것. NCS 사이트에는 폐지된 능력단위의 학습모듈 PDF가 그대로 남아 있어서, 교재를 먼저 찾고 거기 적힌 코드를 그대로 옮기면 사고가 납니다.

확인 방법 — NCS-CATALOG 의 data/competency-units.csv 에 그 코드가 있는지 대조합니다. 편성표 생성기는 현행 데이터만 보여주므로 이 문제가 생기지 않습니다.

3직무 선정

주 세분류 1개 + 보조 몇 개.

연결

직종분류검토

목표 취업직무를 정하고, 거기에 대응하는 NCS 세분류 1개를 주(主)로 확정합니다. 보조 세분류는 필요한 만큼 붙이되 주/보조 구분을 분명히 합니다.

현실의 직무가 NCS 세분류 하나에 딱 떨어지지 않는 경우가 많습니다. 예를 들어 DevOps는 NCS에 세분류가 없어서 20010215 클라우드인프라 + 20010216 PaaS + 20010301 IT시스템관리 + 20010615 SW공급망보안을 섞어야 합니다. 이때도 단가를 결정할 주 세분류는 하나로 정해야 합니다.

4직무모델링

심사에서 "산업현장성"으로 평가되는 부분.

산업체 요구와 채용공고를 분석해 실제 수행직무를 정리합니다. 이 문서가 다음 단계(능력단위 선정)의 근거가 됩니다.

  • 목표 직무의 채용공고 20 ~ 30건을 모아 요구 기술 · 경험을 빈도순으로 정리
  • 지역 산업 수요(권역 공고, 지역 산단 현황)와 대조
  • 기존 수료생 취업처의 실제 업무 내용 확인

이 단계를 건너뛰면 5단계에서 "왜 이 능력단위를 골랐는가"에 답할 수 없게 됩니다. 과정적정성 심사에서 가장 자주 깎이는 지점입니다.

5능력단위 선정

전부 넣는 게 아니라 고르는 것입니다.

도구

편성표 생성기

NCS 기반 훈련기준의 능력단위 가운데 필요한 것을 취사선택합니다. 선택한 근거와 뺀 근거를 함께 문서로 남기세요.

과잉 편성 주의

20010202 응용SW엔지니어링은 능력단위가 27개입니다. 요구사항 확인부터 배포 · 리팩토링 · 테스트 · 자료구조까지 SDLC 전체를 덮습니다. 900시간 과정이라도 27개를 다 제대로 다루긴 어렵습니다.

다 넣어 놓고 시간만 잘게 쪼개면 "형식적 편성"으로 읽힙니다. 덜 넣고 근거를 대는 편이 심사에서 낫습니다.

6능력단위요소 → 교과목 매핑

능력단위 1개 = 교과목 1개가 기본.

기본은 능력단위 1개 = 교과목 1개입니다. 필요하면 쪼개거나 묶을 수 있습니다.

  • 쪼개기 — 능력단위가 크고 시간이 많이 필요할 때 (예: 프로그래밍 언어 활용 → 기초 / 응용)
  • 묶기 — 연속 수행되는 능력단위를 하나의 프로젝트 교과로 (예: 화면 설계 + 화면 구현)

묶을 때도 편성표에는 능력단위코드가 각각 남아야 합니다. 묶어서 코드를 하나로 줄이면 NCS 적용 시간이 줄어듭니다.

8NCS 적용비율

기본요건 심사 항목. 부적합이면 탈락.

NCS 적용비율 = NCS 능력단위 기반 훈련시간 ÷ 전체 훈련시간

NCS 능력단위에 대응하지 않는 교과(취업특강, 자격증 특강, 오리엔테이션 등)는 분자에 들어가지 않습니다. 편성표 생성기의 "NCS 외 교과 시간" 칸에 그 시간을 넣으면 비율이 자동 계산됩니다.

하한선(%)은 연도와 훈련사업에 따라 다릅니다. 당해년도 계획공고와 집체(통합)훈련심사 설명회 자료집에서 확인하세요.

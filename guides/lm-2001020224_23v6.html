알아야 할 것

UI/UX 개념
사용자가 제품과 상호작용 하는 시각적인 요소와 디자인을 의미한다. 예를 들어 웹의 버튼 디자인, 아이콘, 색상 구성 등이 UI의 요소에 해당한다.
UI/UX 구성 요소
(가) 시각적 디자인: 색상, 타이포그래피, 레이아웃, 아이콘 등 사용자가 화면에서 보는 (나) 상호작용 디자인: 버튼 클릭, 스와이프 등 사용자의 조작에 대한 반응 (다) 정보 구조: 콘텐츠의 구성 및 분류 (가) 사용성(Usability): 사용자가 소프트웨어를 얼마나 쉽게 이용할 수 있는지 정도 (나) 유용성(Usefulness): 소프트웨어가 사용자의 요구사항을 얼마나 충족하는지 정도
UI/UX의 관계
UI와 UX는 서로 밀접하게 관계가 있다. 좋은 UX를 위해서는 좋은 UI가 필수적이지만 좋은 UI가 항상 좋은 UX를 보장하는 것은 아니다.
ISO 9241-210
(가) 표준 명칭: ISO 9241-210:2019 (나) 제정 기관: ISO(International Organization for Standardization) (다) 적용 대상 소프트웨어, 웹사이트, 디지털 인터페이스, 기기 설계 등 사용자와 컴퓨터 상호 작용 전반을 적용 대상으로 한다.

알아야 할 것

UI 프로토타입(Prototype) 개념
사용자와 시스템 간의 상호작용을 분석하여 사용성을 테스트하고 사전에 UI의 품질을 확보하기 위하여 시스템 기능 개발 전에 사용자의 요구사항을 반영하여 초안 화면을 설계하는 활동이다.
UI 프로토타입 유형
초기 기획 단계에서 간략하게 구현된 형태로, 사용자의 반응을 신속하게 파악하고 요구사항을 수집하는 데 활용한다.
UI 프로토타입 제작 절차
사용자 요구사항명세서와 시나리오를 분석하고 대표 사용자를 정의하는 등의 분석을 수행하는 단계이다. 메뉴, 정보, 콘텐츠 구조 정리와 화면 간 이동 흐름을 정의하는 단계이다.
초기 프로토타입 설계 도구
와이어프레임, 상호작용 프로토타입, 자동 애니메이트, 클라우드 라이브러리 연동 등의 기능을 제공하는 도구이다.
모사형 프로토타입 제작 도구
클릭, 화면 이동 링크 설정, 플러그인 등의 기능을 제공하여 웹 기반 실시간 협업을 지원하는 제작 도구이다.

사용자 상호작용 중심 설계

적용 수준 구분
서비스 패턴마다 적용 수준을 필수, 권장, 우수의 세 단계로 나누고, 시나리오에서 어느 수준까지 구현 및 준수할 것인지 제시한다.

각 시나리오 단계에는 접근성 기준을 적용하며, 고령자와 장애인을 포함한 다양한 사용 자 환경을 고려하여 설계한다.
상호작용, 피드백, 오류 처리
사용자의 행동 이후 시스템의 반응, 입력 오류 처리, 장애 발생 시 대응 절차 등을 시 나리오에 반드시 포함한다.
공통 요소와 반복 패턴 활용
시나리오는 가이드라인에서 제시한 컴포넌트, 기본 패턴, 스타일 가이드를 기반으로 작성하고 재사용이 가능하도록 구조화한다.
실제 사용자 데이터 기반 구성
설문, 사용자 의견, 행동 데이터, 평가 결과 등을 근거로 실증적인 사용 패턴과 문제 상황을 반영하여 시나리오를 작성한다.
화면 사용 도움 정보 포함
화면 내 도움말 정보는 흐름도와 시나리오에 포함하며, 특히 복잡한 흐름은 사용자가 명확한 안내를 받을 수 있도록 설계한다.

1UI 요구사항과 표준 및 지침에 따라, 사용자의 편의성을 고려한 메뉴 구조를 설계한다.
  1. UI 상세 설계를 위한 요구사항을 최종 확인한다.
  2. UI 설계서 표지 및 개정 이력을 작성한다.
  3. UI 구조를 설계한다.
  4. 메뉴 구조를 설계한다.
  5. 개별 화면을 설계한다.
2UI 요구사항과 표준·지침을 토대로 하위 시스템 단위의 내부·외부 화면과 입력 폼을 설계한다.
  1. 실행 부담을 줄이기 위한 UI 설계 원칙을 검토한다.
  2. 평가 부담을 줄이기 위한 UI 설계 원칙을 검토한다.
3UI 설계 결과를 평가한다.
  1. UI 설계 결과를 반복적으로 평가한다.
  2. UI 검토 결과를 반영한다.
  3. 사용성에 대해 전문가 및 내부 개발자가 검토 및 검증을 수행한다.

스스로 확인

  • UI 요구사항과 표준 및 지침에 따라, 사용자의 편의성을 고려한 메뉴 구조를 설계한다.
  • UI 요구사항과 표준·지침을 토대로 하위 시스템 단위의 내부·외부 화면과 입력 폼을 설계한다.
  • UI 설계 결과를 평가한다.
  • UI 요구사항과 UI 표준 및 지침에 따라, 사용자의 편의성을 고려한 메뉴 구조를 설계할 수 있다.
  • UI 요구사항과 UI 표준 및 지침에 따라, 하위 시스템 단위의 내외부 화면과 폼을 설계할 수 있다.

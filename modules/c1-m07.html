07. 생성형 AI 기반 프로덕트 제작

생성형 AI 엔지니어 양성과정 · 20010707 생성형AI엔지니어링

NCS 능력단위 정의 (ncs.go.kr 원문, 29차)
생성형 AI 기반 프로덕트 제작이란 목적에 맞는 출력 기능을 구현하고 입력부터 출력까지 전체 기능이 통합된 프로덕트를 제작하는 능력이다.
능력단위코드 2001070707_25v1 NCS 수준 5 편성 훈련시간 28 기간 2026-11-24 ~ 2026-12-11 본평가 2026-12-11

학습목표

  • 입력 처리부터 출력까지의 흐름을 설계한다.
  • 모델 호출과 출력 가공 기능을 구현한다.
  • 전체 기능을 통합해 동작하는 프로덕트를 만든다.

선수지식

  • 05 프롬프트 구현
  • 06 프롬프트 최적화
  • 웹 애플리케이션 개발 기초

실습

05·06의 프롬프트를 얹어 입력 화면 → 모델 호출 → 결과 표시까지 동작하는 프로덕트를 만든다.

평가

평가방법 작업장평가 · 평가자 체크리스트
능력단위 정의의 수행 절차를 그대로 평가 항목으로 삼습니다. 루브릭 4단계(매우 우수 90~ / 우수 80~ / 보통 60~ / 미흡 60미만), 합격 하한 60점.

교안 작성 메모

시간 배분이 가장 큰 능력단위다. 웹 개발 자체를 여기서 가르치려 들면 시간이 모자란다. 프론트엔드 기초는 선수과목으로 두거나 스캐폴드를 제공할 것.

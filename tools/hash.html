로그인 해시 생성기

이 사이트의 아이디 · 비밀번호를 바꿀 때 씁니다

이 로그인은 보안 장치가 아닙니다. 정적 사이트라서 해시가 assets/auth.js 에 그대로 공개되고, 짧은 비밀번호는 대입으로 뚫립니다. 채점 정답 · 평가문항 원본처럼 새어 나가면 안 되는 것은 이 사이트에 올리지 말고 .gitignore 로 막으세요. 이 로그인은 학생이 우연히 들어오는 것을 막는 가림막 정도로만 씁니다.

바꾸는 방법

  1. 위에서 아이디 · 비밀번호를 넣고 해시를 만듭니다. (비밀번호는 이 브라우저 밖으로 나가지 않습니다)
  2. assets/auth.js 를 엽니다.
  3. 일반 계정이면 H_USER, 관리자 계정이면 H_ADMIN 의 값을 바꿉니다.
  4. git add . && git commit && git push 하면 몇 분 뒤 사이트에 반영됩니다.

해시는 아이디 + ":" + 비밀번호 를 SHA-256 으로 만든 값입니다.
